# Changelog

## 0.1.0 — 2026-11-20

- Three queue routing policies, with identical customer inputs for each comparison.
- Reproducible seeds, three presets, and configurable arrival/service parameters.
- Queue-length SVG chart and scrubbable service/queue replay.
- Customer-level CSV export and parameter permalinks.
- Dependency-free loopback server and a single-file offline build.
- Engine invariants, edge cases, and HTTP integration tests.
- GitHub Pages demo and CI for Node.js 22 and 24.
