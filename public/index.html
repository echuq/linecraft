UNDER THE HOOD

How the model works

Customers arrive at random, with a constant average rate (a Poisson process). Each gets a service time before the comparison starts. Every setup uses those exact same arrivals and service times.

One shared line

The next person goes to the first available window. First come, first served.

Shortest line

Pick the line with the fewest people, including the person being served. Break ties randomly. No switching.

Random line

Choose any window with equal probability. Stay in that line until you're served.

“Some variation” uses an Erlang distribution with shape 4; “lots” uses an exponential distribution. “None” gives everyone the same service time. After arrivals stop, the simulation runs until everyone is done.

No breaks, abandonment, priority customers, walking time, or real-world measurements. The animation replays an already-computed result. At 100% expected load or above, don't interpret this finite run as a stable long-run system.
